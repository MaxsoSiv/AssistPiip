# AssistPiip

Текстовый ассистент для Windows: команды в чате, AI-ассистент, заметки, напоминания, буфер обмена, переводчик, монитор процессов и голосовой ввод. Работает локально, без установки — распаковать и запустить.

Сайт проекта: [maxsosiv.github.io/AssistPiip](https://maxsosiv.github.io/AssistPiip/)

## Возможности

- **Чат-команды** — браузер, проводник, айпи, пинг, заметки, напоминания и таймеры на естественном языке, с распознаванием опечаток.
- **AI-ассистент** — подключите любой OpenAI-совместимый провайдер (в том числе локальную Ollama): стриминг ответов, Markdown, контекст диалога, отмена по Enter. Ключ хранится только в Windows Credential Manager.
- **Выделенный текст** — глобальный хоткей захватывает выделенное в любой программе и предлагает перевод, краткий пересказ и исправление.
- **Голосовой ввод** — диктовка в поле ввода по глобальному хоткею.
- **Свои команды** — триггеры с алиасами и цепочками действий; шаблоны `{selection}` и `{clipboard}` подставляют выделенный текст и буфер обмена.
- **Плагины без кода** — JSON-манифесты в `data/plugins/` добавляют команды без правки ядра.
- **Заметки** с закреплением и историей версий (10 последних редакций).
- **Буфер обмена** — история текста и картинок с поиском и закреплением.
- **Калькулятор** — обычный, инженерный, программистский (DEC/HEX/OCT/BIN).
- **Переводчик** — 12 языков с автоопределением.
- **Монитор процессов** — цветовая маркировка безопасности процессов.
- **Спотлайт** — мини-строка у курсора: поиск по командам, заметкам и буферу.
- **Горячие клавиши** на всё: окно, спотлайт, выделенный текст, голосовой ввод.
- **Тема оформления** — 6 тем, свой цвет акцента, прозрачность, плавающий кружок.
- **Обновления** — автопроверка, скачивание с проверкой SHA-256 и allowlist-доменов.

## Горячие клавиши (по умолчанию)

| Действие | Комбинация |
|---|---|
| Показать/скрыть окно | `Ctrl+Alt+P` |
| Спотлайт у курсора | `Ctrl+Alt+K` |
| Захват выделенного текста | `Ctrl+Alt+T` |
| Голосовой ввод | `Ctrl+Alt+V` |

Все комбинации меняются в настройках.

## Установка

1. Скачайте ZIP со [страницы релизов](https://github.com/MaxsoSiv/AssistPiip/releases).
2. Распакуйте архив.
3. Запустите `AssistPiip.exe` — установка не требуется.

Для голосового ввода в сборке должны присутствовать пакеты `SpeechRecognition` и `PyAudio`.

## Сборка из исходников

```bash
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
.venv\Scripts\pip install pyinstaller
.venv\Scripts\pyinstaller AssistPiip.spec
.venv\Scripts\python tests\test_core.py
```

Готовая сборка появится в `dist/AssistPiip/`.

## Структура проекта

```
main.py            точка входа
core/              платформо-независимое ядро: менеджеры данных, LLM-провайдер, updater
ui/                интерфейс на PySide6: окна, темы, сплэш, попапы
win/               Windows-адаптеры: хоткеи, автозапуск, захват выделенного
assets/            иконки
tools/             утилиты разработчика
docs/              сайт проекта (GitHub Pages)
tests/             тесты ядра
```

## Приватность

Все данные (история буфера, заметки, команды, чат) хранятся только локально в папке `data/`. Телеметрии, аналитики и скрытых сетевых запросов нет. В интернет приложение обращается только по вашей инициативе: проверка обновлений, перевод, распознавание речи и запросы к выбранному AI-провайдеру. Резервные копии данных создаются локально в `data/backups/` и хранятся 7 дней.
